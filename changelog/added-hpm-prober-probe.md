Added HPM Probe X USB support (VID 0x34b7, PID 0x8003/0xe001). The default RISC-V DMI tunnel uses advertised SBA and Program Buffer memory offloads when safe; an explicit raw JTAG sequence mode uses the generic RISC-V transport. Both modes support four-wire JTAG and, with compatible firmware, two-wire cJTAG. Physical reset-pin control is not supported.
